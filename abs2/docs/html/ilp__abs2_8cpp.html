Detailed Description

Solves an Integer Linear Programming (ILP) problem using ABS2 solver through QUBO++ library.

This is a sample program to solve the following Integer Linear Programming (ILP) problem using EasySolver through QUBO++ library.

Maximize
2 * x + 3 * y
Subject To
c1: x + y <= 7
c2: 3 * x + 5 * y <= 28
Bounds
x <= 7
y <= 5
Generals x y End
