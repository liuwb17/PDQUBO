Detailed Description

API for calling the ABS2 QUBO solver from the QUBO++ Library.

This API provides a way to call the ABS2 QUBO solver from the QUBO++ Library. It includes the following classes:

  • Solver: A class for calling the ABS2 QUBO solver, derived from abs2::Solver.
  • QuadModel: A class for storing both the qbpp::QuadModel and abs2::Model, derived from qbpp::QuadModel and containing an abs2::Model object.
  • Param: A class for setting parameters for the ABS2 QUBO solver, derived from abs2::Param.
  • Sol: A class for storing the ABS2 QUBO solution, derived from qbpp::Sol and containing an abs2::Sol object.
  • Callback: A class for defining the ABS2 callback function, derived from abs2::Callback and containing a qbpp::QuadModel object.

Please refer to Sample Programs for examples of how to use these classes.
