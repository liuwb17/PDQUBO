Detailed Description

This file contains an example of solving the bin packing problem using the EasySolver.

The bin packing problem is a combinatorial optimization problem that is concerned with packing items of different sizes into bins of fixed size in a way that minimizes the number of bins used. In this example, we consider a bin packing problem with 4 bins and 8 items. The weights of the items are given as {33, 61, 58, 41, 50, 21, 60, 64}. The goal is to find a way to pack the items into the bins such that the total weight of items in each bin is at most 120.
